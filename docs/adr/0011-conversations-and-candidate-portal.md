# ADR 0011：候选人 H5 自助入口与持久化沟通

状态：比赛版核心链路已实现。B06 统一交付，外部渠道与 AI 执行能力继续归对应模块验收。

## 已实现的行为

- HR 候选人详情页生成 72 小时专属链接。候选人通过链接查看本人资料、公开应聘状态和 H5 消息，无须 HR 账号；可先咨询再授权。链接使用独立 JWT audience，服务端保存可撤销的签发记录。重新签发使旧链接失效；合并 / 撤销合并使涉及身份的链接全部失效。删除档案同步物理删除会话与链接。
- Token 放 URL fragment，通过 Authorization 请求头使用，不进入查询串；候选人页面及接口使用 no-referrer。链接提供本人资料访问能力，HR 需先核对身份再分享。发链接只是生成待分享内容，没有自动向任何邮箱、手机或飞书发消息。
- 招聘 / AI 评估授权、撤回、不再联系均保存本人操作证据。撤回和不再联系立即取消待发内容、清除防抖任务并阻止 HR 新发送；已送达消息继续保留。本人仍可发起沟通与资料请求。
- 支持本人更正请求、15 天处理期限、HR 记录核实处理结果；删除请求由 HR 核实后使用已有物理删除操作完成。更正请求不会未经验证就覆盖身份字段，也没有将“提交请求”显示为“删除成功”。
- HR 接管后人工发送，交还进入待处理状态。原接管人离职时，招聘负责人可填写交接说明后接管或交还并留痕。没有配置 AI 自动回复，因此不会生成假 AI 回答。候选人明确提出“不再联系”或“转人工”时直接处理，无须模型。
- 消息按候选人统一归档，带关联应聘、发送方、H5 渠道和时间。HR 仅可读取全部关联岗位均在其范围内的消息；无岗位标签的通用沟通要求完整岗位范围。业务经理及管理员身份本身不获得会话权限。候选人看不到内部原因、评估、排队 / 已取消消息。
- 主动消息默认北京时间 9–21 点送达；对最近 30 分钟来信的回复可在 7–23 点送达。其余内容排队到次日 / 当日 9 点。候选人新增消息使旧问题的待发回复失效。恢复调度时重新检查安静时段、授权、HR 在职权限、接管状态、岗位状态及最新来信。
- HR 淘汰时可选择下一个工作日 10 点发布 H5 结束通知，支持配置节假日 / 调休。真正写入可见消息时才标记 sent 并公开“已结束”；送达前撤销淘汰会取消队列。不会把排队当作送达，也不向候选人公开淘汰原因。

## 事务、恢复与实时更新

迁移 `0010` 新增 `comm.conversation`。比赛规模下，状态、链接元数据、消息与待发时间保存在一个加密聚合内；使用已有组织配置事务锁串行化写入，并检查 expected_version。消息、授权、应聘通知状态、审计 / 事件及幂等回执同事务提交。幂等回执仅缓存对象 ID，重试会重新校验身份和权限并重建当前 DTO，删除后不能通过旧回执取回资料。

API 后台每 2 秒处理会话队列和 10 秒持久化来信防抖。多个实例共享数据库锁，进程重启后从数据库继续；H5 消息写入可见状态即算页面送达，无第三方调用和回执伪造。防抖到期进入待人工处理，为 B09 AI 编排保留事件接入点。

HR 和候选人 SSE 只传候选人 ID / 版本，连接期间持续复核身份与可见范围。客户端使用带 Bearer 头的 fetch 流，断线重连读取当前版本，同时保留 5 秒轮询兜底。业务数据始终通过受控接口重新获取，连接不会持有跨等待的数据库事务。写入网络故障保留原正文和幂等键；版本冲突刷新后需人工再次提交。

## 部署与检查

- 使用锁定依赖运行 `alembic upgrade head`，本机开发数据库已升级至 `0010`，`alembic check` 通过。
- `CANDIDATE_PORTAL_URL` 配置候选人实际可访问的页面地址，开发默认 `http://localhost:5175`。生产应使用 HTTPS，不能把 localhost 链接发给远程候选人。
- `CONVERSATION_WORKER_ENABLED` 默认开启。部署已有 `POSITION_HOLIDAYS` / `POSITION_WORKDAYS` 配置同时供淘汰通知日历使用。
- Compose 的 web profile 增加 candidate-h5（5175）。本机 Docker Linux 引擎当前未运行，容器启动不能视为已验收。
- 新增 21 项后端专项，覆盖签名 / 撤销 / 过期 / audience、未授权咨询、幂等与并发 CAS、静默窗口、隐私取消、跨岗消息隔离、旧回执权限重查、重启恢复、失效回复、实际队列送达、通知撤销 / 公开状态、资料请求与物理删除、接管人离职后的交接。
- 浏览器新增 HR / 390px 候选人 H5 联调、丢响应重试、实时授权与接管、资料更正回执、撤回与链接失效、缺失 / 错误链接；截图已检查。

## 未提前验收的能力

目前仅 H5 渠道真实送达，短信、邮件、飞书及第三方回执尚未接入。AI 草稿 / 自动回复、主动联系频控与追问上限、24 小时条件交还、工作时间催办升级和跨模块决策卡由 B08 / B09 实现。当前交还会话不会启用 AI。

候选人时区目前统一使用北京时间；时区设置、自动到期匿名化、生产限流、消息分页 / 索引化队列、负载与恢复演练归 B10。加密聚合和全局事务锁适用于比赛演示规模，不能据此声称大规模生产吞吐已验证。真实面试排期与评价进入 B07，当前候选人页面没有模拟可预约时段。
