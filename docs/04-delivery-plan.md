## 目前发现的前端缺口

- 三端目前默认内存 mock；上游未安装真实依赖验证。
- HTTP 配置未传入登录 token；真实模式没有可用登录入口。
- 部分 POST 没有幂等键；前端统一写操作在网络失败时重置键，可能导致重复提交。
- “保存草稿”原来只跳转，没有持久化；“历史复制”“驳回或转交”没有完整实现。
- 需求表单缺少序列、替补人、追加岗位、保密可见人员；薪资/日期以自由文本提交。
- 列表直接使用数组，与设计中的服务端分页不同，需要渐进兼容，而非一次性改坏所有页面。

## 外部配置依赖

后续接入需要飞书应用、Dify 工作流/API 凭据、对象存储和短信/会议配置。先实现端口和本地测试，实际凭据仅存 `.env`，不提交仓库。部署验收不能把开发目录/开发登录算成飞书接入完成。
